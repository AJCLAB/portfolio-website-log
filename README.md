# AJCLAB portfolio LOG

Publieke leer- en werklog voor de portfoliowebsite.

Deze map bevat een leesbare statische pagina op `/portfoliowebsite/LOG/`. De log beschrijft verzoeken, beslissingen, controles en verbeterregels voor volgende opdrachten. Er worden geen toegangstokens, wachtwoorden of privégegevens opgeslagen.

De log is een werkdocument voor betere uitvoering in volgende verzoeken. Het is geen automatische modeltraining en verandert geen modelgewichten.
